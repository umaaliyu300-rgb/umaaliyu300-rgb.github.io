Privacy Policy

Last updated: 18 November 2026

Who this covers

Hidden Engine Publisher ("the app") is private software used only by the owner of the YouTube channel The Hidden Engine to manage that channel. It is not offered to other users.

Google data the app accesses

With the owner's permission, given through Google's sign-in screen, the app uses these YouTube Data API permissions:

  • youtube.upload: to upload videos and thumbnails, and set their details, on the owner's channel.
  • youtube.readonly: to read basic information about the owner's channel and videos, such as the channel name, handle and view counts.

How the data is used and stored

  • The data is used only to publish and manage the owner's own channel.
  • Google sign-in tokens are stored only on the owner's computer, in Windows Credential Manager.
  • Channel information is processed on the owner's computer. It is not sold, shared with third parties, or used for advertising.
  • The app does not collect data from viewers or from any other Google account.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Removing the stored token from the owner's computer deletes the app's local copy.

Contact

Questions about this policy can be sent through the channel's YouTube About page.
